Locus — first launch on macOS
=============================

This build is NOT signed with an Apple Developer ID, so macOS Gatekeeper
will refuse to open it the first time. This is expected, and it is not a
virus warning — it means Apple has not been paid to vouch for the app.

To install and open it:

  1. Drag "Locus.app" into your Applications folder.
  2. In Applications, right-click (or Control-click) Locus, and choose Open.
  3. Click Open in the dialog that appears.

You only need to do this once. After that, Locus opens normally.

If macOS says Locus "is damaged and can't be opened" and offers to move it
to the Trash
------------------------------

DO NOT move it to the Trash. The file is not damaged — this is the message
macOS shows instead of the accurate one when an app is unsigned and was
downloaded from the internet. Run this in Terminal, and then repeat steps
1 to 3 above:

    xattr -cr /Applications/Locus.app

You can open Terminal from Applications > Utilities > Terminal. Copy the
line above, paste it in, and press Return. It removes the quarantine flag
that macOS put on the download; it does not change the app itself.

If step 2 still does not offer Open, try: double-click Locus to trigger the
warning, then open System Settings > Privacy & Security, scroll down, and
click "Open Anyway" next to the Locus message.

Why it is unsigned
------------------
Signing requires a paid Apple Developer account. It is a known gap and will
be handled separately.

If Locus still will not start
-----------------------------
Open Terminal and run:

    /Applications/Locus.app/Contents/MacOS/locus

and send us the text it prints. That output says what actually went wrong,
which is a different problem from this warning and is worth reporting.
