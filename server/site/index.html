Locus VPN

A lightweight VPN client for Windows, macOS and Linux.

You need a Locus code to sign in. The client installs without one, but will not connect until a code is entered.

Download

  • Windows Windows 10 and 11, 64-bit · installer
  • Linux x86_64 · executable
  • macOS Apple Silicon (M-series) · .app
  • macOS Intel · .app

Verify your download against the published manifest.

How it works

  1. Download the build for your platform.
  2. Install it, and open Locus.
  3. Enter your code, then connect.
